# sRFTM — Small Rubium Formula Transformer Model

Маленькая модель, которая превращает неформальные математические записи в LaTeX.
**Лицензия:** Apache 2.0

## Пример

| Вход                 | Выход                            |
| ------------------------ | ------------------------------------- |
| `x^2 = 9`              | `x^{2} = 9`                         |
| `deriv(x^3-4) = f(x)`  | `\frac{d}{dx}(x^3 - 4) = f(x)`      |
| `sum n=1 to inf 1/n^2` | `\sum_{n=1}^{\infty} \frac{1}{n^2}` |

## Идея

- Маленькая модель (1–5M параметров), не GPT.
- Маленький датасет (1k–10k пар), не терабайты.
- Обучается на Colab T4 за 1–4 часа.
- Узкая задача: формулы в учебных конспектах.
- Apache 2.0, открытый код, авторство закреплено.

## Гибрид

1. Regex на входе (70% случаев, <1ms).
2. Модель на остатке (30%, 50–200ms).
3. LLM API как fallback (<0.7 confidence).

## Стек

- Python, PyTorch.
- Google Colab для обучения.
- HuggingFace для публикации.
- ONNX для деплоя.
